# 하루 한 걸음 · 한국어 여행

세종한국어2의 학습 순서를 참고해 새로 만든 초급 한국어 학습 앱입니다. 기존 앱 코드는 사용하지 않았습니다.

## 실행

```sh
npm install
npm run dev
```

개발 서버가 표시하는 주소를 브라우저에서 엽니다. 빌드는 `npm run build`입니다.

## 현재 구현 범위

- 14개 단원과 문화 코너 4개를 순서대로 학습할 수 있습니다.
- 일반 단원은 **대화 1 → 어휘 1 → 문법 1 → 대화 1 연습 → 대화 2 → 어휘 2 → 문법 2 → 대화 2 연습 → 듣기 → 말하기 → 읽기 → 쓰기 → 마무리 퀴즈**로 구성됩니다. 문화 코너는 창작 읽기와 이해도 확인으로 구성됩니다.
- 각 대화 연습에는 내용 확인 문제, 3단계 힌트, 낱말 순서 맞추기가 있습니다.
- PPTX에 보이는 단원별 핵심 어휘·표현 146개를 추가했습니다. 전체 어휘 색인을 전수 반영한 것은 아닙니다.
- 모든 문법 항목에 결합 형태, 쓰임, 주의점, 예문 2개 이상을 제공합니다.
- 단어 그림 기호, 대화의 영어 뜻, 한국어 합성 음성, 듣기 대본, 쓰기 초안 저장 기능을 제공합니다.
- 기본 설명 언어는 한국어입니다. 왼쪽 패널에서 영어·일본어·중국어·베트남어·네팔어·태국어·우즈베크어·몽골어를 선택할 수 있습니다. 모바일에서는 상단에 선택 메뉴가 표시됩니다. 한국어를 선택하면 영어 어휘 뜻과 대화 번역을 숨깁니다. 다른 언어를 선택하면 활동 안내와 주요 문법 설명을 해당 언어로 표시하며, 어휘 뜻과 대화 번역은 현재 영어로 제공됩니다.
- 정답 검증 뒤 XP와 완료 기록을 저장하고, 다음 단원 잠금 판단에 사용합니다.
- 어휘 활동에 들어가면 브라우저 로컬 저장소에 첫 복습 일정을 만듭니다. 복습에서 틀린 단어는 오늘 복습에 남습니다.
- 잠긴 단원은 보상 없이 둘러볼 수 있고, 정식 학습을 완료하면 다음 단원이 열립니다.

첨부된 세종한국어2 PPTX의 단원 주제와 주요 문형을 참고했습니다. 예문·대화·퀴즈·문화 읽기는 새로 작성했으며, 교재 원문과 삽화를 복제하지 않았습니다. 어휘 색인의 각 표제어 전체를 옮긴 콘텐츠는 아니며, 현재 각 단원은 대표 어휘 중심입니다. 브라우저의 `localStorage`에만 진도가 저장되므로 기기 간 동기화는 아직 지원하지 않습니다.

콘텐츠는 `content/manifest.json`과 `content/units/*.json`에 분리돼 있습니다. 콘텐츠를 처음부터 다시 생성할 때는 `generate-content.mjs` → `enrich-content.mjs` → `expand-material.mjs` → `grammar-details.mjs` 순서로 실행합니다. 1과의 기본 내용은 `u01.json`에서 별도로 관리합니다.

구조 검사는 `node verify-content.mjs`, 대화 연습 흐름 검사는 `node verify-app-flow.mjs`로 실행합니다.
